INTRODUCCIÓN\r\nSaludCerca es una plataforma web para localizar centros municipales de salud de La Paz, Bolivia, solicitar fichas médicas y recibir orientación con IA. Se propone migrarla a Google Cloud Platform para mayor escalabilidad, disponibilidad y seguridad.\r\n\r\n### 3. MARCO TEÓRICO\r\n- Cloud Computing: Acceso bajo demanda a recursos informáticos vía Internet.\r\n- IaaS: Infraestructura virtualizada. (Compute Engine)\r\n- PaaS: Plataforma para desarrollar/desplegar apps. (Cloud Run)\r\n- SaaS: Software listo para usar.\r\n- Google Cloud Platform: Suite de servicios en nube de Google.\r\n\r\n### 4. PROBLEMA - OBJETIVO\r\nProblema: Dificultad para localizar centros, conocer disponibilidad y obtener fichas médicas en La Paz.\r\nObjetivo General: Proponer la migración de SaludCerca a Google Cloud Platform.\r\nObjetivos Específicos: Identificar servicios, adaptar arquitectura, proponer seguridad/red, garantizar observabilidad.\r\n\r\n### 5. LISTA DE SERVICIOS Y SU DESCRIPCIÓN\r\n| N° | Servicio | Categoría | Aplicación a SaludCerca | Modelo |\r\n|---|---|---|---|---|\r\n| 1 | Cloud Run | Cómputo | Despliega backend NestJS sin servidor, HTTPS, escalado automático | PaaS |\r\n| 2 | Cloud SQL (PostgreSQL) | Bases de Datos | Migración BD PostgreSQL + Prisma, backups, cifrado, alta disponibilidad | DBaaS |\r\n| 3 | Cloud Storage | Almacenamiento | Aloja frontend React+Vite como sitio estático | IaaS |\r\n| 4 | Cloud IAM | Seguridad | Roles/permisos con menor privilegio entre servicios | Seguridad |\r\n| 5 | VPC + Serverless VPC Access | Redes | Conexión privada Cloud Run - Cloud SQL | IaaS/Redes |\r\n| 6 | Cloud Logging & Monitoring | Observabilidad | Logs, métricas, dashboards y alertas | PaaS/Ops |\r\n\r\n### 6. CONCLUSIÓN\r\nSe propone migrar SaludCerca a GCP con los 6 servicios para mejorar escalabilidad, seguridad, disponibilidad y accesibilidad.\r\n\r\n### 7.
